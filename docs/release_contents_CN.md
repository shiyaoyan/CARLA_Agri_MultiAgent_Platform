# GitHub 发布目录说明

本目录面向论文复现、CARLA 电脑部署和 GitHub 发布。

## 包含内容

- `agri_carla/`：PGA、SGA、MCA、CIA、EEA、TPS、PES 及 CrewAI Flow；
- `roadrunner_mcp/`：OpenDRIVE、FBX 和纹理生成模块；
- `configs/`：烟台轨迹跟踪、贝叶斯优化、全流程导航和原始影像场景模板；
- `data/trajectory/yantai_quanlujing.csv`：论文示例实测轨迹；
- `data/experiment_results/section_3_1/`：论文 3.1 节五类路径跟踪实验的原始输出；
- `scripts/`：同机双环境安装、Flow 启动和领域工具入口；
- `tests/`：架构、控制器、LLM、道路拓扑、运行时和发布一致性测试；
- `docs/`、`README.md`、`README_CN.md`：安装、运行和故障排查说明。
- `LICENSE`：MIT 开源许可证。
